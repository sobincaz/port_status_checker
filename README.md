

# Port Status Checker

A Python-based TCP Port Status Checker developed using the `socket` library to identify open, closed, and filtered ports on a target host.

## Features

- Target IP address input
- Custom port range selection
- TCP connection testing
- Open, Closed, and Filtered status detection
- Timeout handling

## Technologies Used

- Python
- Socket Programming
- TCP/IP

## How to Run

bash

```bash
python port_checker.py
```
